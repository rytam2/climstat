# climstat

This repository contains all notebooks and code to access and extract variables from publicly available gridded climate datasets, calculate decadal statistics of climate metrics, and output .csv files at county or zipcode level. This documentation details the operations conducted in creating the data shown in the climate database for the Illinois Department of Public Health and Illinois Emergency Management Agency. This work is built on [climate_map](https://github.com/mailesasaki/climate_map), written by Maile Sasaki. 

### Updates as of February 8th, 2026: 
**Currently supported dataset(s) include:**
- ERA5 at 0.25 degree resolution

**Currently supported climate metrics are as follow:**
- Heat Index
- Wet Bulb Globe Temperature
- Wind Chill
- Tornadoes (Events, Impacts)
- Air Quality Index  

If you require additional statistics or other climate metrics not listed above, please reach out to Rachel Tam (rytam2@illinois.edu).
